# Raw sources

Immutable inputs that agents compile into [the wiki](../wiki/index.md): original plans, design notes, bank CSV **header** samples, renovation quotes, product notes and so on.

- Add files; never edit or delete existing ones. A correction is a new file.
- Name files `YYYY-MM[-DD]-<slug>.md` (or the original extension).
- **No personal financial data.** Scrub statements down to column headers and one or two fake rows before adding them. Never add account numbers, real balances or credentials.
- After adding a source, ask an agent to *ingest* it (see [AGENTS.md](../../AGENTS.md#wiki-operations)).
