# Planner

**Idea: a possible `planner` layer** for shared todos and a calendar. The user described it as "maybe?", so the scope is open.

## Options

- **Shared todos:** lists with an assignee (person or joint), a due date and recurring chores. Can link to house tasks or meals.
- **Calendar:** show what's on from existing calendars (Google Calendar API or CalDAV) rather than building a new calendar. Showing upcoming bills, fixed-rate end dates and project milestones there would tie the domains together.

## Open questions

- Which calendar provider(s) the household uses.
- Whether house project tasks should just be todos (shared core concept) or stay separate.
